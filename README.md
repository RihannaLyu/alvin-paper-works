# Alvin Paper Works

Live site: https://rihannalyu.github.io/alvin-paper-works/

To preview it on your own computer, double-click `index.html` and it opens in your browser.

## Adding your crafts
1. Take a photo of each piece, ideally sitting on your fingertip against a plain background. Save it in `media/`, e.g. `media/tiny-scissors.jpg`.
2. For working tools, film a short clip (5–15 seconds) of it working and save it as `.mp4` in the `media/` folder.
3. Open `crafts.js` and copy one of the blocks. Change the title, kind (`"figure"` or `"tool"`), size, image, video and about text.
4. Save, then upload the changed files to this GitHub repository. The live site updates within a minute or two.

## Files
- `index.html`: the page structure
- `styles.css`: colors, fonts and layout (colors are at the top)
- `main.js`: the fingertip zoom, the filters and the viewer
- `crafts.js`: your list of pieces (the file you'll edit most)

## Before putting it online
Keep personal details off the site: no last name, school, home town or personal email/phone.
